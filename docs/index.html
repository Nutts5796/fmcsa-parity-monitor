FMCSA Data Parity Monitor

A weekly, reproducible check of public FMCSA carrier registration data on data.transportation.gov, run with the open-source LogiParity CLI.

What is checked. (1) The Company Census File read twice, through its paginated JSON API and as a CSV export, with the same filter. These should always agree. (2) The monthly SMS motor carrier census against the active records of the daily Company Census, joined by USDOT number. These are different publications with different refresh schedules and, for some fields, different definitions, so differences are expected. They are not claims that either dataset is wrong.

What is published. Counts, totals and cause summaries only. Carrier names are not compared and no per-carrier records are published.
